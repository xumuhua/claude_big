## 证伪原因分析

1. **信息同源**：LLM 评级全部由动量/均线/波动数据佐证（prompt 强制），与量化 score 同源——veto/scale 只是把同一信号**加一个月滞后**再用一遍。
2. **滞后致命**：月末评级在 V 反月恰好挡住再入场（2015-10、2020-04、2022-11 型），而轮动策略的利润恰恰来自这些右侧再入场。
3. **职能重叠**：系统性风险防御已由净值熔断 MA150 承担（自适应、逐日响应）；risk_off 月度缩放是更钝的同一工具。

## 与主线 LLM 范式为何不同

主线 LLM 复盘提供的是**量化体系没有的信息**：主线归并、题材叙事、行业关联（文本知识）→ 有增量。ETF 池 10 个标的、纯宏观资产，量化特征已覆盖 LLM 可推理的几乎全部信息 → 无增量。**LLM 的价值与池内资产数量/叙事复杂度正相关。**

## 使用方式（保留层）

```bash
python3 scripts/monthly_llm_analysis.py            # 默认跑最近月末(增量)
python3 scripts/monthly_llm_analysis.py --months 202608 --force   # 月初重算当月(月末序列取当月最后交易日, 跨月后需force刷新)
```

每月产物 = 宏观叙事备忘 + 上月自我校验，供人工决策参考；**不接入回测与实盘指令**。

## 已知局限

- 豆包知识截止晚于回放月份，存在"认出名场面"的隐性 lookahead——但消融结论（无增量）不受此影响：即使有 lookahead 优势仍然跑输。
- 并行回放时上月评级链式传递为机会主义（盘上已有则用）；如需严格链式可 `--workers 1` 顺序重跑，不影响本报告结论。
